# O que acontece depois desta manifestação

A manifestação da Procuradoria-Geral do Estado é registrada no repositório da
auditoria como ato, vinculado ao conjunto a que se refere. Ela não altera
sozinha o catálogo em vigor.

Para que a proposta passe a valer, quatro requisitos precisam estar
simultaneamente satisfeitos, e cada um é ato de alguém:

1. cada regra proposta dos grupos aprovados promovida ao estado que a libera
   para o sistema;
2. decisão de completude registrada para cada grupo ativado;
3. decisão de completude registrada para a composição como um todo; e
4. ato institucional do Instituto que ative a composição no lugar da atual.

Enquanto os quatro não se completarem, o catálogo hoje vigente continua sendo
o único em vigor, e a exportação operacional para o Sisprev continua saindo
integralmente dele. Nenhum desses requisitos é presumido pelo gerador deste
documento: o que não tiver sido praticado e registrado aparece como
pendência, nunca como concluído.
