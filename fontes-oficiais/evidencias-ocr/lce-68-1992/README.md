# Evidência de OCR da LCE 68/1992

O PDF oficial do SAPL (`../../arquivos/sapl-LC68-1992.pdf`) é uma digitalização
sem camada textual. As 86 páginas foram renderizadas a 180 DPI e processadas
pelo Tesseract 5 com o modelo `por` de `tessdata_fast`.

O resultado integral preservado aqui é evidência intermediária e pode conter
erros. Os arts. 137, 235 e 236, usados pelo Ciclo 9, foram cotejados diretamente
com as páginas 41 e 71 da publicação original renderizada; só esse cotejo
sustenta os dispositivos destilados.
